# 🌈 Pastimes

**Wear it again. Sell it again.**

Pastimes is a vibrant, community-driven used clothing marketplace where users can buy and sell second-hand fashion in a social, engaging, and nostalgic environment. The platform blends e-commerce with social media interaction to create a modern thrift-shopping experience.

---

## ✨ Overview

Pastimes is designed to make second-hand shopping:
- More **social**
- More **visual**
- More **personal**
- More **trust-driven**

It combines the best elements of modern resale platforms like Depop-style social engagement and Vinted-style simplicity, while adding a nostalgic, colorful aesthetic inspired by early internet culture and vintage fashion spaces.

---

## 🎯 Key Features

### 👕 For Buyers
- Browse a visual, social-style product feed
- Like, comment, and follow sellers
- View detailed product pages (images, price, condition, seller info)
- Direct messaging with sellers
- Add items to shopping cart
- Secure checkout flow (buyer protection included)
- Personalized product recommendations
- Advanced filtering (brand, size, price, condition, category)

---

### 🛍️ For Sellers
- Account registration and login
- Create personalized seller profiles (mini thrift store pages)
- Upload and manage clothing listings
- Chat directly with buyers
- Track inventory and mark items as sold
- No commission fee system (highlighted feature)

---

### 🛡️ Admin System
- Approve seller registrations before they can list items
- Remove sold or inappropriate listings
- Monitor transactions and delivery status
- Communicate with buyers and sellers
- Act as a liaison between users when needed

---

## 🌐 Core Platform Features

- 📱 Social media-style feed (likes, comments, follows)

## 🎨 Design Philosophy

Pastimes is built around a **nostalgic, expressive, and colorful aesthetic**:

- Inspired by early 2000s internet culture
- Retro thrift store visuals
- Bright, playful color palettes
- Polaroid-style image cards
- Sticker-like UI elements
- Slight grain/noise textures for nostalgia
- Mix of handwritten and modern typography

### Color Palette
